# ТЕРМА — термокружка 500 мл

Одностраничный лендинг термокружки: чистый HTML, CSS и немного JS. Иллюстрация
кружки нарисована инлайн-SVG, поэтому страница работает без внешних зависимостей
и картинок.

## Что внутри

- `index.html` — разметка страницы и SVG-иллюстрация кружки;
- `styles.css` — оформление, адаптив, анимации (учитывает `prefers-reduced-motion`);
- `app.js` — переключение цвета корпуса и состояние кнопки «В корзину».

## Как посмотреть

Открой `index.html` в браузере — сборка и сервер не нужны.

## Детали

- Три варианта цвета корпуса: графит, песок, хвоя.
- Адаптив от 320 px, на мобильных иллюстрация поднимается над текстом.
- SVG-градиенты берут цвета из CSS-переменных, поэтому палитра меняется одним
  атрибутом `data-variant` на `<body>`.
